## Problema e objetivo

Preservar histórico de uma atividade de frontend/eventos, sem simular um aplicativo que ainda não existe.

Este é um estudo/experimento de engenharia de software; não é declarado como serviço comercial, produto em produção ou solução universal.

## O que existe atualmente

Antes da curadoria, repositório vazio: nenhuma implementação pública observável. Os arquivos originais, licenças, histórico e eventuais instruções de instalação permanecem no repositório. Esta curadoria não executou todas as dependências nem comprovou operação funcional. Para executar, use as instruções originais do README se disponíveis; quando ausentes, a preparação do ambiente é uma tarefa pendente, não um comando inventado.

## Projeto, autoria e referências

Registro pessoal associado ao Ignite Lab; participação não certificada. Créditos, fontes de tutoriais e colaboradores devem continuar associados ao trabalho original. O fato de um repositório estar nesta conta não significa que todo o conteúdo foi escrito individualmente.

**Primeiro passo:** Acrescentar código e testes somente se a atividade voltar a ter escopo real.
